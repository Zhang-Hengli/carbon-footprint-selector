# AI 碳足迹因子选择器

基于 Ollama 本地大模型 + ChromaDB 向量数据库的 LCA 碳足迹因子智能推荐工具。

## 功能

用户输入原材料信息（CAS号、产品名称、活动名称、生产工艺），AI 从 ecoinvent 数据库中选择最匹配的碳足迹因子。

## 文件说明

| 文件 | 说明 |
|------|------|
| `init_db.py` | 初始化向量数据库（首次使用只需运行一次） |
| `app.py` | 网页界面程序 |
| `requirements.txt` | Python 依赖 |
| `ecoinvent数据库信息-给AI.xlsx` | ecoinvent 原始数据 |

## 使用步骤

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 初始化向量数据库（首次使用只需运行一次）

```bash
python init_db.py
```

首次运行会下载 Sentence-Transformer 模型（约 90MB），需要等待几分钟。

### 3. 启动程序

```bash
python app.py
```

然后在浏览器打开 http://localhost:7860

## 技术方案

- **向量检索**：Sentence-Transformer (all-MiniLM-L6-v2)
- **向量数据库**：ChromaDB
- **字段权重**：CAS号(35%) > 产品名称(30%) > 活动名称(20%) > 工艺描述(15%)
- **大模型**：Ollama + qwen2.5:7b

## 系统要求

- Python 3.10+
- Ollama（已安装 qwen2.5:7b 模型）
- 16GB+ 内存
